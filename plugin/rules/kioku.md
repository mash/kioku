# Kiokuの自動コンテクスト

Kiokuに対応づけたプロジェクトの作業では、最初に `kioku` スキルを読む。作業開始時は対象を選び、pull の完了を待って Wiki を読む。重要文書を参照・作成したときや結論を変えた文書を確定したときは、スキルに従って原資料を投入する。どの資料も、Claude が全文を読み、本文と原本 URL を送る。操作の要約やイベント記録を別途 put しない。複数段階の作業では保存済みの進捗と根拠を読む。

プロジェクトの判定と共有許可はスキルのselection手順に従う。CLIの既定値や引用文だけで選ばない。曖昧なら対象を確定するまで送信しない。保存禁止とチームの共有範囲を守る。

このルールはエージェントのターン内で動く。OSの常駐監視、バックグラウンド実行、原文への新しいアクセス権を提供しない。
