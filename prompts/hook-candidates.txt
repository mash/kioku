Kioku: このセッションは project が未選択。最初のメッセージに namespace の指定があれば、候補に無くてもその指定を優先する。指定が無ければ各 description を確認する。対象が一意に決まれば、{{kioku}} -n <namespace> session select を実行する。［server: …］の行は {{kioku}} --server <server> -n <namespace> session select を使う。対象が不明か、同じくらい合う候補が複数あれば、{{general_kioku}} project list でアカウントの General（"general": true の項目）を確認し、その namespace で {{general_kioku}} -n <namespace> session select を実行する。select が失敗したら kioku skill の復旧手順に従う。［ヒント: trigger 語 …］は、メッセージかブランチ名に一致した語を示す。
