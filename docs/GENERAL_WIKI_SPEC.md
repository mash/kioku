# Kioku General Wiki の外部仕様

## ユーザースラッグと個人組織

ユーザースラッグは、アカウントごとに異なる URL 用の名前。
サインアップ時に選ぶ。Kioku はメールアドレスの `@` より前を整形し、入力欄の初期値にする。
整形後の値が予約語なら `user-<値>`、無効なら `user` を初期値にする。
半角小文字と数字を使い、区切りには単独のハイフンを使う。長さは1〜63文字。
Kioku は無効な値、予約語、使用中の値を拒み、理由を表示する。利用者は入力し直せる。
利用者は登録後にユーザースラッグを変更できない。

個人組織は、ユーザースラッグを組織のスラッグに使う組織。
Kioku はサインアップ時に個人組織を1つ作る。
個人組織には通常のプロジェクトを作り、別のアカウントを共同オーナーに追加できる。
共同オーナーは自分のアカウントを削除できる。Kioku は他の利用者の個人組織から、その共同オーナーのオーナー権限だけを外す。個人組織と General は残す。
アカウント削除後の90日間は、誰も同じ値をユーザースラッグや組織のスラッグに使えない。
90日が過ぎると、誰でも同じ値を使える。

## General と権限

General は本人専用の Wiki プロジェクト。Kioku はサインアップ時にだけ1つ作る。
プロジェクトの識別名（namespace）は `<ユーザースラッグ>/general`。
`team/general` など、同じスラッグの別プロジェクトは通常のプロジェクトとして扱う。

| 操作 | Kioku の動作 |
| --- | --- |
| General への招待、オーナー移譲、単独削除 | HTTP 409 を返す |
| General を含む組織のオーナー移譲 | HTTP 409 を返す。共同オーナーは追加できる |
| General に参加していない組織オーナーによる閲覧 | アクセスを拒む |
| アカウントの削除 | General とその内容を削除する。HTTP 409 を返す場合は何も削除しない |
| 個人組織に General 以外のプロジェクトが残る場合のアカウント削除 | HTTP 409 を返す |
| HTTP 503 を返したアカウント削除の再試行 | 失敗の原因を解消すれば、削除を完了する |
| 削除中のアカウントによるプロジェクト作成、またはその個人組織でのプロジェクト作成 | HTTP 409 を返す |

組織のオーナーを移譲すると、Kioku は移譲先にオーナー権限を与え、操作したオーナーの権限だけを外す。ほかの共同オーナーの権限は残す。

## 一覧と会話での選択

API の `GET /api/projects` と MCP の `projects_list` は、本人の General にだけ `"general": true` を付ける。
一覧に内部プロジェクト ID は出さない。CLI の `kioku project list` とローカルの `projects.json` もフラグを使う。
General の説明文は提案しない。

利用者が namespace を指定したら、ローカル一覧に無くても指定を優先する。
trigger 語が1つのプロジェクトにだけ一致すると、フックはそのプロジェクトを自動選択する。
利用者のメッセージに別の namespace の明示指定があれば、Claude はその namespace を選び直す。
指定した namespace がフックの候補に無ければ、General を探す接続先でその namespace を選ぶ。
指定が無ければ、選択済みのプロジェクトか、最初のメッセージに一意に合うプロジェクトを使う。
対象を絞り込めない場合は、一覧の `"general": true` の項目から General を選ぶ。
コネクターの一覧に対象が無ければ、同じアカウントで対象を許可して再接続する。
