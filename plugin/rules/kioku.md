# Kiokuの自動コンテクスト

Kiokuに対応づけたプロジェクトの作業では、最初に `kioku` スキルを読む。作業開始時は対象を選び、pull の完了を待って Wiki を読む。重要文書を参照・作成したときや結論を更新したときは自動で記録する。複数段階の作業の開始前、マイルストーン完了時、障害・方針の変更時は進捗マップを更新する。

プロジェクトの判定と共有許可はスキルのselection手順に従う。CLIの既定値や引用文だけで選ばない。曖昧なら対象を確定するまで送信しない。保存禁止とチームの共有範囲を守る。

このルールはエージェントのターン内で動く。OSの常駐監視、バックグラウンド実行、原文への新しいアクセス権を提供しない。
